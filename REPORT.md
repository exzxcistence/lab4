# Лабораторная работа №4. Ансамбли и полносвязные нейронные сети

## Данные и подготовка

В `german.csv` 1000 записей, 20 признаков и целевой столбец `Creditability`. Положительный класс `1` встречается 700 раз, класс `0` — 300 раз. Пропусков и полностью одинаковых строк нет.

Данные разбиты в отношении 80/20 со стратификацией по целевому классу. В train 800 записей, из них 560 класса `1`. В test 200 записей, из них 140 класса `1`.

Числовые и порядковые признаки, например сумму кредита и стаж, передаю как числа и стандартизирую. Номинальные признаки, например цель кредита, тип жилья и наличие поручителей, кодирую one-hot. Масштабирование нужно полносвязной сети. Пайплайн также предусматривает заполнение пропусков медианой для числовых признаков и наиболее частым значением для категориальных. Параметры преобразований вычисляются на обучающей части каждого фолда, а при финальном обучении — на всём train.

## Гипотезы и эксперименты

| Модель | Настройки и гипотеза |
| --- | --- |
| Extra Trees | 300 деревьев, минимум 5 наблюдений в листе и 80% признаков на разбиение. Случайные разбиения и усреднение могут снизить разброс предсказаний. |
| Gradient Boosting, глубина 1 | 180 деревьев, скорость обучения 0,035. Деревья с одним разбиением проверяют, насколько достаточно отдельных вкладов признаков. |
| Gradient Boosting, глубина 2 | 160 деревьев, скорость обучения 0,035. Второй уровень даёт деревьям возможность учитывать взаимодействия признаков. Число деревьев уменьшено из-за большей сложности каждого дерева. |
| MLP | Один скрытый слой из 8 нейронов, ReLU, оптимизатор L-BFGS, коэффициент L2-регуляризации 8 и до 1000 итераций. Регуляризация ограничивает сложность сети на небольшой выборке. |
| Soft Voting | Равновесное среднее вероятностей двух вариантов Gradient Boosting и MLP. Проверяем, улучшает ли усреднение ранжирование объектов по сравнению с каждой моделью отдельно. |

## Метрики

Каждая запись из train получила вероятность от модели, обученной на остальных четырёх фолдах. Метрики посчитаны по объединённым отложенным предсказаниям. Критерий выбора — максимальный ROC-AUC. Для accuracy, precision, recall и F1 использован порог 0,5.

| Модель | ROC-AUC | Accuracy | Precision | Recall | F1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Extra Trees | 0,7602 | 0,7538 | 0,7886 | 0,8857 | 0,8343 |
| Gradient Boosting, глубина 1 | 0,7474 | 0,7213 | 0,7350 | 0,9411 | 0,8254 |
| Gradient Boosting, глубина 2 | 0,7635 | 0,7400 | 0,7643 | 0,9089 | 0,8303 |
| MLP | 0,7576 | 0,7513 | 0,7945 | 0,8696 | 0,8303 |
| **Soft Voting** | **0,7681** | 0,7438 | 0,7677 | 0,9089 | 0,8324 |

На отложенном test после обучения выбранной модели на всех 800 записях train:

| Модель | ROC-AUC | Accuracy | Precision | Recall | F1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Soft Voting | 0,8240 | 0,7800 | 0,7963 | 0,9214 | 0,8543 |

## Выбранная модель

Выбран Soft Voting. Он получил наибольший ROC-AUC на кросс-валидации. Для каждого объекта ансамбль усредняет три вероятности класса `1`. При среднем значении от 0,5 присваивает класс `1`, иначе класс `0`.

## Выводы и ограничения

Вариант бустинга с глубиной 2 показал ROC-AUC на 0,0160 выше варианта с глубиной 1. В этих двух конфигурациях различалось и число деревьев, поэтому разницу нельзя полностью приписать глубине. Усреднение добавило около 0,0046 ROC-AUC относительно лучшего отдельного бустинга. Extra Trees получил наибольший F1 при пороге 0,5. При другом критерии выбора итоговая модель могла бы поменяться.

Разница между лучшими моделями небольшая. Один датасет и одно разбиение дают ограниченную оценку того, как модель поведёт себя на новых данных. Порог 0,5 фиксирован для сравнения и не учитывает возможную разницу в цене ошибок двух классов.

## Воспроизводимость

Использованы Python 3.13, pandas 2.3.3 и scikit-learn 1.8.0. Для разбиения 80/20, перемешивания пяти стратифицированных фолдов и обучения моделей задаётся seed 42.

Из корня проекта запустите:

```bash
python run_experiments.py
```

Скрипт повторяет кросс-валидацию, запускает контрактную функцию на отложенной выборке и записывает измеренные значения в `experiment_results.json`.
